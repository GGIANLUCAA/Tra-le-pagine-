3D Pop-Out Studio

Prova Android senza account e senza API a pagamento. Separa Socrate con tocchi sul dipinto e simula l'uscita dalla cornice. Questo è un effetto 2.5D, non una vera mesh 3D.

Socrate · David · 1787Standard · 720 × 12800 crediti AI

1 · Carica il dipinto autentico

Opera CC0: The Death of Socrates · Metropolitan Museum. Scarica prima la fotografia sul telefono e selezionala qui. Il file resta sul dispositivo.

Senza sfondo pulito useremo una copertura sfocata nella zona selezionata: è solo una simulazione, non un restauro affidabile.

2 · Disegna il contorno di Socrate

Tocca punti successivi lungo il profilo del personaggio, compresi braccio e tunica. Almeno 3 punti. Su Android puoi usare il dito; più punti migliorano il taglio. Seleziona solo Socrate.

0 punti. La maschera indicativa è una sagoma grezza da rifinire, non un'estrazione automatica AI.

3 · Guarda l'uscita dal quadro

L'esportazione video usa MediaRecorder nel browser, se compatibile. WebM non è MP4. L'MP4 H.264 richiede successiva conversione (es. FFmpeg in GitHub Actions CPU), non inclusa in questo laboratorio.

Carica il quadro originale per iniziare. Nessun file viene inviato a server esterni.
Stato: prototipo sperimentale. Nessuna integrazione con il renderer 4×1, Vidu, la coda, l'archivio o la pubblicazione. La proiezione della foto su un piano mobile è un'illusione 2.5D, non mostra lati reali della figura. La cornice di prova è una ricostruzione scenografica, non la cornice storica documentata.
