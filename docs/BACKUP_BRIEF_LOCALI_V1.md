# Backup dei brief salvati nel browser

## Cosa viene salvato

Quando premi **Conserva questa scheda**, il menu salva le impostazioni del brief nel browser e sul dispositivo che stai usando. Il salvataggio non si sincronizza automaticamente con altri telefoni o browser e non equivale al piano di produzione completo `PROJECT_V13.json`.

Il menu conserva fino a 40 brief. Il backup contiene soltanto le informazioni compilate nel menu: titolo, idea, format, tipo di progetto, stile, durata, lingua, voce, piattaforma e preferenze. Non contiene video, immagini o password. Il file può comunque includere idee non pubbliche: custodiscilo come un tuo documento.

## Fare una copia di sicurezza

1. Apri **Nuovo video** e scorri fino a **Progetti salvati sul telefono**.
2. Premi **Esporta backup JSON**.
3. Sul telefono Android, scegli **Download** o una cartella in cui conservi i tuoi documenti. Se vuoi ritrovare il file anche cambiando telefono, copialo tu su Drive o in un altro spazio che usi.
4. Non premere **Elimina brief locali** finché non hai verificato che il file sia presente.

Puoi esportare di nuovo dopo aver salvato altri brief. Il file include tutti i brief che il browser conserva in quel momento.

## Recuperare i brief

1. Apri lo Studio nel browser in cui vuoi ripristinare i brief.
2. Apri **Nuovo video** e premi **Importa backup JSON**.
3. Seleziona il file esportato e conferma l’importazione.
4. I brief vengono uniti a quelli già presenti. Se due copie hanno lo stesso identificativo, prevale quella del backup. Lo Studio conserva al massimo 40 brief per volta.

Se il file non è JSON valido o supera 2 MB, l’importazione viene rifiutata senza sostituire il contenuto salvato.

## Limite da ricordare

Il backup è una copia manuale trasferibile: non attiva la sincronizzazione online. Un brief importato o salvato resta nel browser e nel dispositivo finché non lo esporti o non lo elimini. Per il progetto completo, materiali, fonti, render e revisioni, l'agente deve poi creare e conservare i file di produzione previsti dalle regole attive.
