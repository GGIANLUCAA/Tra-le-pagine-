▧ ASSET INTELLIGENCE

Archivio media

Cerca materiali già esistenti prima di generarne nuovi. La ricerca V7 gira su GitHub, non sul telefono.

I risultati arrivano negli Artifact della run GitHub. Per Pexels serve la chiave configurata sul repository. Openverse V7 cerca fotografie indicizzate da Wikimedia.

IMPORTA UN ELEMENTO SCELTO

Hai trovato una fotografia o clip utile?

Inserisci l'ID riportato nella galleria V7. Usa la stessa fonte e lo stesso tipo di file della ricerca: il download avviene su GitHub.

Il file verrà salvato in un artifact temporaneo, con crediti e provenienza da controllare. Non sarà pubblicato né inserito nel video automaticamente.

Riusare, non ricreare.

V7 può importare un file alla volta dopo una scelta esplicita. L'inserimento automatico di filmati nel render resta una fase successiva.
