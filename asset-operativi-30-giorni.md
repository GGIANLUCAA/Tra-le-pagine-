## SEZIONE C — 10 SCRIPT COMPLETI (faceless, ~25-35s)

Formato scrittura: **[HOOK a schermo]** → voce → b-roll → **[TESTO CHIAVE]** → descrizione+hashtag.

### 1. Tool del giorno
- **Hook (0-2s):** "Questo tool AI gratuito fa il lavoro di [ruolo]." (testo grande su schermo)
- **Voce:** "Si chiama [TOOL]. [Cosa fa] in un clic. Io lo uso per [uso pratico]. Gratis, online, senza account." 
- **B-roll:** screen-recording del tool + zoom sul risultato.
- **Testo chiave:** "GRATIS · 1 clic · [Risultato]"
- **Descrizione:** `Il tool AI che uso ogni giorno per [risultato]. Salva per dopo 🔖`
- **Hashtag:** `#aitools #productivity #tech #fyp`

### 2. 3 tool in 1
- **Hook:** "3 tool AI che sostituiscono [ruolo] — tutti gratis."
- **Voce:** "Uno: [X]. Due: [Y]. Tre: [Z]. Salva questo video."
- **B-roll:** 3 split-screen demo rapide.
- **Testo chiave:** nomi tool + "GRATIS"
- **Descrizione:** `3 tool AI gratis che nessuno ti dice. Quale testi per primo?`
- **Hashtag:** `#aitools #techtips #productivity #fyp`

### 3. Prima vs Dopo
- **Hook:** "Prima: 2 ore. Dopo: 30 secondi. Guarda."
- **Voce:** "Stesso compito, con l'AI. Ecco come."
- **B-roll:** split-screen processo lento vs risultato AI.
- **Testo chiave:** "2 ore → 30s"
- **Descrizione:** `Da 2 ore a 30 secondi con l'AI. Se ti serve, salva 🔖`
- **Hashtag:** `#ai #productivity #workhack #fyp`

### 4. "Non lo sapevi"
- **Hook:** "Non sapevi che [TOOL] facesse QUESTO."
- **Voce:** "Funzione nascosta: [spiegazione in 1 frase]. Provala ora."
- **B-roll:** zoom sulla funzione nascosta, freccia.
- **Testo chiave:** "Funzione nascosta 🤫"
- **Descrizione:** `La funzione nascosta di [TOOL] che il 90% ignora.`
- **Hashtag:** `#aitools #lifehack #tech #fyp`

### 5. Errore comune
- **Hook:** "Smetti di usare l'AI così."
- **Voce:** "L'errore #1: [errore]. Fai così invece: [soluzione]."
- **B-roll:** X rossa sull'errore → ✓ verde sulla soluzione.
- **Testo chiave:** "❌ → ✅"
- **Descrizione:** `L'errore che ti fa perdere tempo con l'AI. Salva.`
- **Hashtag:** `#aitips #learning #productivity #fyp`

### 6. Comparazione
- **Hook:** "[A] vs [B]: quale conviene davvero?"
- **Voce:** "Su prezzo [A] vince, sulla qualità [B]. Per te che [uso] scegli [X]."
- **B-roll:** due prodotti affiancati, barre di confronto.
- **Testo chiave:** "A vs B"
- **Descrizione:** `[A] o [B]? Il confronto onesto in 30s.`
- **Hashtag:** `#ai #review #tech #fyp`

### 7. Prompt pronto
- **Hook:** "Copia questo prompt e trasforma [X]."
- **Voce (leggi il prompt lentamente + testo a schermo):** "[PROMPT]." 
- **B-roll:** prompt digitato + risultato.
- **Testo chiave:** il prompt intero, word-by-word.
- **Descrizione:** `Prompt pronto per [risultato]. Salva e usalo 🚀`
- **Hashtag:** `#promptengineering #aitools #chatgpt #fyp`

### 8. Novità/News
- **Hook:** "[Novità] è appena uscito. Ecco cosa cambia per te."
- **Voce:** "In 20 secondi: [cosa è]. Perché conta: [impatto]. Cosa fare: [azione]."
- **B-roll:** screenshot ufficiale + reazioni.
- **Testo chiave:** "NEW"
- **Descrizione:** `[Novità] spiegata semplice. Ti serve?`
- **Hashtag:** `#ainews #tech #ai #fyp`

### 9. Risposta a commento
- **Hook:** "Mi hanno chiesto: [domanda]."
- **Voce:** "Risposta in 20 secondi: [soluzione]."
- **B-roll:** screenshot del commento → demo.
- **Testo chiave:** la domanda in alto.
- **Descrizione:** `Domanda vostra, risposta mia 👇 Chiedi nei commenti!`
- **Hashtag:** `#faq #aitools #tech #fyp`

### 10. Mito da sfatare
- **Hook:** "No, l'AI NON [credenza comune]."
- **Voce:** "Sfatiamo: [verità in 1 frase] + [cosa fare davvero]."
- **B-roll:** ❌ sulla credenza → ✅ sulla verità.
- **Testo chiave:** "Mito vs Realtà"
- **Descrizione:** `Il mito sull'AI che continua a girare. Salva ✅`
- **Hashtag:** `#ai #myths #tech #fyp`

**Regola comune:** sottotitoli SEMPRE · musica dalla libreria della piattaforma · CTA soft unica · loop finale = inizio.

## SEZIONE F — PIPELINE DI AUTOMAZIONE (step-by-step)

### Livello 1 — oggi (manuale assistito)
1. Calendario editoriale su **Notion / Google Sheets** (usa la Sezione D).
2. Account su **Metricool** o **Buffer** (gratis) → collega i 3 profili.
3. Schedula i video negli slot della Sezione D.

### Livello 2 — tra 1-2 settimane (semi-auto)
1. Script → **AI** (ChatGPT/Gemini) con i template Sezione C.
2. Voce → **ElevenLabs (free)** o **Coqui TTS**.
3. Video → montaggio su **template CapCut** (stesso stile ogni volta) + **sottotitoli automatici** (CapCut o **Whisper**).
4. Collega i pezzi con **n8n**: "nuova riga nel foglio → genera script → notifica → schedula".

### Livello 3 — mese 2+ (full pipeline faceless)
1. Generazione video → **MoneyPrinterTurbo** o **ShortGPT** (dal topic all'MP4).
2. Avatar/voce → **SadTalker**, **Wav2Lip**, **Piper**.
3. Sottotitoli → **faster-whisper**.
4. Grafica/b-roll → **Canva**, **ComfyUI**, **Krea/Leonardo**.
5. Scheduling multi-piattaforma → **Postiz** (`gitroomhq/postiz-app`) o **Mixpost**.
6. Pubblicazione → **API UFFICIALI**: YouTube Data API · Meta Graph API · TikTok Content Posting API.

> ⚠️ API non ufficiali / bot = violazione ToS → ban. Usa solo API ufficiali o tool che le usano.
> Il tuo **sistema-regia** si collega come "modulo produzione" tra il passo 1 e il passo 5.
